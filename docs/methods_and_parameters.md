# 成员 A：方法、模型与参数说明

本文对应 A 阶段六项任务，代码入口为 `src/preprocessing.py` 与 `src/cropping.py`。

## 1. 批量读取、EXIF 与元信息

- OpenCV：`np.fromfile + cv2.imdecode(IMREAD_UNCHANGED)`，用于兼容 Windows 中文路径并验证像素是否能解码。
- Pillow：读取 JPEG/PNG 真实格式、原始宽高、色彩模式、EXIF Orientation、拍摄时间、相机厂商和型号。
- `ImageOps.exif_transpose`：只执行一次 EXIF 方向矫正，矫正后重新记录宽高。
- SHA-256：按 1 MiB 分块计算文件摘要，用于追踪原文件和构造稳定 `image_id`。
- 单文件失败不会中止批次；结果通过 `status/error` 记录。

## 2. 原图保护

- 原始路径只读，代码中不对原文件调用 `save`。
- 成功文件另存为无损 PNG：`data/processed/<group_id>/<image_id>.png`。
- 保留可用的 ICC 色彩配置；输出副本不复制 EXIF/GPS，避免方向被下游重复应用及隐私信息外泄。

## 3. 最多 7 个候选取景区域

候选先生成，再做边界检查、去重和数量限制。输出坐标采用 `[left, top, right, bottom]`，右/下边界不包含在裁剪内。

| 方法 | 参数值 | 含义 |
|---|---:|---|
| 原图候选 | 优先级 0 | 永远保留完整构图 |
| YuNet 人脸检测 | score `0.90` | 仅保留置信度不低于 0.90 的人脸框；不是 90% 准确率 |
| YuNet NMS | IoU `0.30` | 重叠框 IoU 超过阈值时抑制低分框 |
| YuNet top-k | `5000` | NMS 前最多保留的检测框数量 |
| 人脸检测缩放 | 最长边 `1600 px` | 限制检测计算量，坐标映射回原图 |
| 人脸取景扩张 | `2.0 倍` | 人脸联合框周围保留环境，避免只裁出头像 |
| 常见比例 | 横图 `1:1/4:3/16:9`；竖图 `1:1/3:4/9:16` | 在原图内计算最大内接矩形 |
| 显著性 | Spectral Residual | 用频谱残差生成显著图，再求加权质心作为偏移中心 |
| 显著性后备 | Sobel `ksize=3` | contrib 算法不可用时，以边缘能量估计主体中心 |
| 显著性缩放 | 最长边 `1200 px` | 限制计算量，中心映射回原图 |
| 最小候选尺寸 | `64 px` | 防止产生无法使用的极小裁剪；小原图按原尺寸放宽 |
| 去重阈值 | IoU `0.98` | 几乎相同的候选只保留一个 |
| 返回上限 | `7` | 符合作业要求 |

人脸主模型为 OpenCV Zoo 的 YuNet ONNX。Haar/LBP 仅在 YuNet 模型或接口无法加载时降级使用；YuNet 正常运行但检测为 0 时不会启用级联，避免“为了产生人脸候选而强行误检”。动物、建筑和静物由显著性候选覆盖，不能把显著性主体框描述成动物人脸检测。

## 4. 边界与异常测试

- `tests/test_preprocessing.py`：普通图、中文路径、EXIF=6、透明 PNG、损坏图、BMP、不匹配的伪扩展名、原图未改动。
- `tests/test_cropping.py`：横图、竖图、超长图、边界、重复框、7 个上限。
- 真实样本回归：宇航员应有人脸候选；埃菲尔铁塔和狗图不应进入人脸池。该规则验证检测器的泛化行为，不依据文件名做特殊判断。

## 5. 数据与标识

完整规则与样例在 `docs/data_spec.md`；空白表位于 `data/annotations/`。最终提交老师的是原始照片对应的 `source_id`，`crop_id` 仅供候选追踪。

## 6. 实验指标

`scripts/run_a_experiment.py` 逐文件记录预处理结果、耗时、候选来源、候选数量和有效率，并汇总：

- 预处理成功率 = 成功文件数 / 输入文件数；
- 预期结果正确率 = 与样本清单期望状态一致数 / 输入文件数；
- 裁剪成功率 = 成功生成候选的正常图片数 / 正常图片数；
- 候选有效率 = 去重后的合法候选数 / 原始候选数；
- 平均耗时使用 `perf_counter` 的墙钟时间，仅用于同一环境内对比。

真实样本与许可在 `data/sample/real_cases/SOURCES.md`，实验输出在 `outputs/experiments/real_cases/`。
